# Leads folder rules

These rules apply to this folder only.

- **Practice data only.** Everyone in `leads.csv` is a made-up person, for practice. None of them is real.
- **No real people.** Never add a real person's name or a real email address to any file in this folder.
- **Consent on every row.** Every row needs a value in the `consent` column, such as `waitlist form`. Don't add a row without one, and don't leave the column blank.
- **Keep the @example.com addresses.** Every email address ends in `@example.com`. That domain is reserved and can never receive mail. Never change these addresses or swap them for another domain.
